# SourceDayZ — DayZ Source

Este repositório contém o código-fonte do SourceDayZ.

## Aviso obrigatório: Steam e BattlEye

**NÃO remova o Steam nem o BattlEye deste projeto.**

- A integração com a **Steam** (`steam_api64`, Steamworks e arquivos relacionados) é obrigatória e não pode ser removida.
- O **BattlEye** e seus arquivos/serviços de proteção são obrigatórios e não podem ser removidos.
- Pull requests ou alterações que removam, desativem ou substituam a Steam ou o BattlEye **não serão aceitos**.
- Essa regra vale para o cliente, o servidor e qualquer script de build, instalação ou empacotamento.

Mantenha a Steam e o BattlEye intactos em qualquer alteração.
